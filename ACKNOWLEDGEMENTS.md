# Acknowledgements

## Danus

Chalxius gratefully acknowledges the authors of **Danus**, a separate published
system for coordinating mathematical-reasoning agents around a Fact Graph
memory. Its public design informed Chalxius's fact-graph layout and
compatibility with 16-hex logical content identifiers.

Danus 0.2.12 is used here only as a behavioral performance reference and a
frozen legacy-fact import source. It is not a runtime dependency, and no Danus
source code is inherited in this distribution. Chalxius remains an independent
system with its own admission, provenance, learning, and reader contracts.

### Citation

Jihao Liu, Guoxiong Gao, Zeming Sun, Bin Wu, Shurui Liu, Jiedong Jiang,
Haocheng Ju, Leheng Chen, Ronnie Cheng, Xiping Zhang, and Bin Dong. “Danus:
Orchestrating Mathematical Reasoning Agents with Fact-Graph Memory.”
arXiv:2607.06447v2 [cs.AI], 2026.

- Paper: <https://arxiv.org/abs/2607.06447>
- Danus source: <https://github.com/frenzymath/Danus>

## Grill Me

Chalxius also thanks **Matt Pocock** for publishing the public
[`/grill-me`](https://github.com/mattpocock/skills/blob/main/docs/productivity/grill-me.md)
skill in the
[`mattpocock/skills`](https://github.com/mattpocock/skills) project. Its
one-question-at-a-time decision-tree interview, including the practice of
inspecting a codebase instead of asking the user for discoverable facts,
inspired the requirements-discovery method used to shape the Chalxius Reader.

This is interaction-design attribution, not runtime composition. Chalxius does
not invoke or require Matt Pocock's `/grill-me` skill, and the upstream skill is
not bundled in the Chalxius release archive.
