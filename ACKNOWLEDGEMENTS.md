# Acknowledgements

Chalxius gratefully acknowledges the authors of **Danus**. The public Danus
design informed Chalxius's fact-graph layout and compatibility with 16-hex
logical content identifiers.

Danus 0.2.12 is used here only as a behavioral performance reference and a
frozen legacy-fact import source. It is not a runtime dependency, and no Danus
source code is inherited in this distribution. Chalxius remains an independent
Chalk-native integration with its own admission, provenance, learning-plane,
and reader contracts.
