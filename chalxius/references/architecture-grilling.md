# Legacy architecture-grilling path

This filename remains as a compatibility-only routing note. It is not an active
Chalxius teaching protocol and must never be loaded merely because a task
mentions software architecture.

Use the two distinct, on-demand surfaces:

- For proof, paper, or philosophical-argument architecture, ordinary analysis,
  reconstruction, challenge, repair, or refutation stays on the Chalxius
  research surface. It does not activate a learner.
- For academic teaching, paper learning, examination, mastery, or spaced review,
  activate the internal `Chalxius Learner` only when the user explicitly asks
  for that behavior. Follow
  [unified_learning_plane.md](unified_learning_plane.md) and
  [fact-graph-grilling.md](fact-graph-grilling.md).
- For explicitly requested Socratic programming requirements, architecture,
  implementation, debugging, testing, or rollout assistance, use the external
  `$grill-me` skill, publicly distinguished as `Grill Me Code`. It is globally
  available to routing, but availability does not satisfy this intent gate.

Ordinary Chalxius research does not activate Chalxius Learner. Ordinary coding
does not activate Grill Me Code. Grill Me Code cannot mount Fact, Paper, Audit,
Blackboard, or Learning Graph artifacts and has no research authority.
