# Chalxius Learner bounded document-edit bootstrap

This is a nontruth, fail-closed startup projection for one bounded edit of an
existing academic teaching Markdown file.  It changes no Research, Candidate,
Certification, Gateway, Fact, Learning Graph, project authority, or release
state.

## Applicability selector

Use this projection only when every condition holds:

1. the user explicitly activated Chalxius Learner teaching;
2. the target is one existing workspace Markdown teaching document;
3. the edit is confined to one named section or a small consecutive section
   range;
4. the edit reorganizes or explains definitions, formulae, and arguments that
   are already supported by one exact frozen Paper, Fact, Audit, or Blackboard
   source slice;
5. no new research result, correctness certification, Fact admission,
   persistent mastery update, global architecture change, or external action is
   requested.

If any condition is false or uncertain, use the ordinary applicable Chalxius
path.

## Complete compact startup

After reading the complete root `SKILL.md`, read only:

1. the current request and applicable workspace instructions;
2. this bootstrap;
3. the target section, one adjacent structural unit on each side, and every
   definition or notation actually used there;
4. the exact frozen source slice supporting the edit;
5. a task-scoped CHX ledger when the edit is project-bound.

Do not preload unified release, admission, attack-routing, full Paper/Fact,
Blackboard, capability-matrix, PHX, or Learning-Graph protocols merely because
they exist.  Load one only if its fail-closed trigger below occurs.

## Edit and QA contract

- List the local objects, notation, input statements, and output statement
  before editing.  Define every nonstandard term before first use.
- Preserve literal hypotheses, quantifiers, domains, coordinates, conventions,
  and claim scope from the exact source slice.
- Touch only the named section range and the smallest adjacent text required for
  definition-before-use closure.  A nonlocal reorganization exits this path.
- Record target and source paths plus before/after SHA-256 values.
- Check the diff boundary, heading hierarchy, Markdown/TeX delimiters, HTML
  blocks, symbol uniqueness, map domains/codomains, and any available local
  renderer or linter.
- Perform a no-chat-context check: the resulting file must be understandable to
  its intended reader without the conversation.

## Fail-closed expansion

Stop the compact path and load the ordinary applicable references when:

- the source, Fact Graph, and teaching text conflict or a source defect is
  suspected;
- the user asks for fresh verification, Research, Candidate, Certification,
  Gateway, or Fact work;
- a persistent Learning Graph, Paper/Audit, or Blackboard mutation is needed;
- the edit becomes nonlocal, its source slice is insufficient, or local QA
  finds a defect outside the authorized range;
- Chalxius code, runtime, configuration, manifest, version, architecture,
  installation, publication, or another external effect is in scope.

This projection removes unrelated startup reads.  It never weakens source
fidelity, mathematical correctness, document QA, or truth authority.
